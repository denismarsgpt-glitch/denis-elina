# Denis y Elina

Página para propietarios: quiénes somos, de qué vivimos, qué piso buscamos, documentos y contacto. En castellano, inglés y catalán.

https://denismarsgpt-glitch.github.io/denis-y-elina/

Las copias de los documentos no están en este repositorio. La página enlaza a los PDF en Google Drive, con los números de documento, las firmas, las fechas de nacimiento, las direcciones y las cuentas tapados.
